# Новая героиня: постная кухня на копейки (концепция, 2026-10-09)

> Проработка: `docs/POST_CHANNEL.md` (выбран образ A, лист `assets/heroine/sheet_A.png`).

Учебный герой (мужчина-«лекарь», футболка «ХРЕН ИИШНЫЙ») — только для обкатки конвейера.
Рабочий канал — женщина 50–60 лет, православная, простые бюджетные блюда, в конце — сколько стоит.

## Образ
- Возраст 52–60, добрая, спокойная, «своя»: не повар-шеф, а хозяйка, которая кормит семью на скромные деньги.
- Фирменная деталь, по которой узнают в ленте: тёмно-синий льняной фартук с вышитой веточкой рябины.
- Кухня с красным углом (икона, лампада) на заднем плане, не в фокусе — православие видно, но не навязчиво.
- Варианты A/B/C: `assets/heroine/var_*.png` (A — сельский дом с печью, B — изба, платок, C — городская кухня).
- Не называть её «матушкой» (так зовут жён священников — вводит в заблуждение). Имя — простое: Нина Петровна и т.п.

## Формат ролика (30–60 с)
1. Хук 2–3 с: готовое блюдо крупно + «Обед на четверых за 160 рублей — и без мяса».
2. Готовка 4–6 коротких планов: продукты → действия (как планы-ингредиенты в образцах 03–05).
3. Подача: героиня пробует, тёплая фраза.
4. **Финал-чек**: продукты и цены строками на экране + «Итого: 158 ₽, по 40 ₽ на человека».
5. Призыв: «Напишите «пост» — пришлю книгу «Постный стол на 40 дней»».

## Серия под Рождественский пост (28.11.2026 — 06.01.2027, 40 дней)
- Рубрика «40 дней поста — 40 блюд», ролик в день: «День 7 из 40».
- Отметки устава дня (монастырский устав, мирянам — по благословению): сухоядение / без масла / с маслом / рыба.
  Календарь по дням — сверить с церковным календарём перед публикацией.
- Разогрев с ~15 ноября: «как подготовиться к посту и не потратить лишнего», закупка круп.
- Праздники внутри поста: Введение (4 декабря, рыба), Никола Зимний (19 декабря), Сочельник (6 января, сочиво).

## Цены
Реальные цены сетей (Пятёрочка/Магнит) на дату съёмки, с оговоркой «цены на ноябрь 2026, Москва».
Цену порции считать по фактическому расходу (200 г гречки из пачки 900 г за 89 ₽ = 20 ₽), а не по пачке.
